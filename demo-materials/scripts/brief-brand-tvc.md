# 用例 B：品牌 TVC（重氛围）

## 输入

```text
做一条 20 秒的品牌形象片。
品牌是一个独立咖啡品牌，主张「慢下来」。
不要口播，用画面和字幕说话。
色调：暖褐、低饱和。
节奏：前松后紧，最后定格在品牌标���。
横屏 16:9。
```

## 期望产物结构

| 环节 | 期望 |
|---|---|
| 剧本 | 无口播或极少量；字幕承担叙事 |
| 角色 | 0–1 位（可只有手部特写） |
| 场景 | 2–3 个（清晨街道 / 咖啡馆 / 桌面特写） |
| 分镜 | 5+ 镜头，运镜有变化（推近 / 环绕 / 特写） |
| 音频 | BGM 为主；可无人声 |
| 成片 | 16:9，≈20s，有 BGM 轨 |

## 验收要点

这个用例专门压**纯字幕 / 无人声**路径：

- 直出链路对「无口播片」的处理（`needs_placeholder_video` 占位画面逻辑）
- 字幕轨是否正常烧录
- **BGM 是否真的进成片**（🔴 G7 缺陷点）

> 若此用例成片没声音，不要绕过——那正是要现场暴露并记录的问题。
