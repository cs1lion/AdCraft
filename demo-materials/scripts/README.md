# 文案脚本素材（创意输入 · 故事改写）

> 用途：实机演示的**创意输入起点**与**故事改写前后对照**。
> 用法：直接把文件里的「输入」段落粘进引导对话框；改写用例照着「改写后」段落替换 slot。
> 全部为原创虚构文案，无第三方版权依赖。

## 目录

| 文件 | 用途 | 对应演示步骤 |
|---|---|---|
| `brief-product-launch.md` | 商品发布主用例（推荐首发） | S1 创意输入 → S8 成片 |
| `brief-brand-tvc.md` | 品牌 TVC（重氛围、轻口播） | S1 → S7 |
| `brief-short-drama.md` | 短剧向（多角色、有冲突） | 拉片复刻改写 |
| `rewrite-cases.md` | **故事改写前后对照**（拉片复刻核心） | P1-4 / 故事改写 |
| `negative-briefs.md` | 负例输入（空、超长、含糊、矛盾） | L4 负例 |

## 使用纪律

1. **演示只用本文档里的文案**，不要临场即兴——即兴文案会让不同场次结果不可比。
2. 每个用例跑完把实际产出存到 `demo-materials/outputs/<日期>/`，
   与本文件的「期望」对照，差异记入演示 summary。
3. 文案质量不在验收范围（见 `live-demo-e2e-plan.md` §0），
   验收的是：文案能输入 → 能生成 → 能改 → 改动能传导到下游。
