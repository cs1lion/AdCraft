# 用例 A：商品发布（首发推荐）

## 输入（粘进引导对话框）

```text
做一条 15 秒的洗发水新品广告。
产品卖点：控油、蓬松、无硅油。
目标人群：25-35 岁加班熬夜的上班族女性。
整体调性：清爽、有活力，不要夸张。
必须有：前 3 秒钩子、价格利益点、行动号召。
竖屏 9:16。
```

## 期望产物结构（用于核对，不用于挑刺）

| 环节 | 期望 |
|---|---|
| 剧本 | 3–5 个镜头，含钩子 / 卖点 / 利益点 / 行动 |
| 角色 | 1 位使用者（女性，成年） |
| 场景 | 至少 1 个（浴室或卧室，产品特写场景） |
| 分镜 | 每镜有景别 + 运镜 + 时长 |
| 音频 | 台词语音 ≥ 2 句；BGM 1 条 |
| 成片 | 9:16，时长 ≈ 15s，**有音轨** |

## 验收要点

- 钩子是否落在前 3 秒（可以在的，不完美也放过）
- 价格利益点与行动号召是否成句（**成句即可，不要求文案好**）
- **成片必须有音轨**（🔴 当前已知缺陷点，见演示方案 §S8）
